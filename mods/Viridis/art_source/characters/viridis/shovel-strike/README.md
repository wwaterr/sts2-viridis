# 小松绿 · 持铲普攻动作样片

敌人在画面右侧。小松绿将重心沉到后腿，抬起短柄园艺铲，蹬地送肩。前手在敌人方向伸直后再下压，弯肘收回腰际，最后回到低持铲的警戒姿势。

| 相对普攻开始 | 姿势 | 用来判断动作的部位 |
| --- | --- | --- |
| 0.00 秒 | 警戒 | 两脚支撑，眼睛朝右 |
| 0.04 秒 | 蓄力 | 屈膝，下沉，持铲肘后收 |
| 0.14 秒 | 举铲 | 后脚提踵，铲刃越过帽檐 |
| 0.20 秒 | 命中 | 铲尖伸到前脚以外，对应角色的 AttackAnimDelay |
| 0.30 秒 | 随挥 | 肩继续朝前，铲尖落向前膝外侧 |
| 0.44 秒 | 收势 | 弯肘，回收铲柄 |
| 0.64–0.76 秒 | 回稳 | 恢复起始姿势，衔接待机 |

原画表为 `poses.png`。内置图像工具使用动作设定 `viridis_action_pose.png` 锁定人物和持铲手，使用卡图参考 `shovel_strike.png` 锁定铲柄、握法和刃形。生成要求为同机位、同尺度、面向右侧的六张连续全身姿势，透明底，省略斩击光效。

`frames/` 保存对齐后的透明关键帧。在 Spine 4.2 的 Import Data 中选取 `shovel-strike.json` 可继续编辑两段时间线。待机循环 2.4 秒。根节点在双脚之间，命中帧前脚掌保持着地。

运行 `node tools/build_shovel_strike.mjs` 重建关键帧、Spine JSON 和 `outputs/viridis-animation/viridis-shovel-strike.webp`。动作预览按角色约 235 像素高输出。本次样片在美术源目录内单独验收，游戏包现用资源位于 `assets/characters/viridis/combat/`。
