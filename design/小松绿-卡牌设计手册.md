# 小松绿 · 卡牌设计手册 v0.1

> 目标：为「栽培」角色设计 112 张卡，支撑两个流派：
> **A. 加速栽培流** —— 缩短倒计时、批量栽培、提前收获
> **B. 栽培库收益流** —— 按「栽培库中的牌数」换取数值收益

---

## 1. 关键词与规则

| 关键词 | 定义 |
|---|---|
| **栽培** | 将 1 张手牌放入**栽培库**，X 回合后收获。X = 该牌**未升级原始费用**，钳制 1~3；状态/诅咒/任务按 1 计 |
| **栽培库** | 独立牌堆，界面独立显示，展示其中的牌与**剩余回合数**；**无上限** |
| **生长 N** | 栽培库中所有牌剩余回合 **-N**（最低 0，到 0 立即收获） |
| **延缓 N** | 剩余回合 **+N**（配套负面或延迟收益） |
| **收获** | 取出该牌，按稀有度升一档生成新牌（先古收同名牌），加入手牌；保留升级状态 |
| **栽培库牌数** | 结算时栽培库中的牌数（含剩余回合 >0 的全部牌） |
| **同接** | 回合内计数：每打出一张牌 +1，回合结束清零；在能量旁显示，非小松绿且牌堆无同接卡时隐藏 |
| **考子** | 回合开始时，获得等同于层数的同接 |
| **反踩** | 每回合前 X 次打出的牌不会获得同接 |
| **串子** | 回合开始时，随机获得 X 次 1 点活力或 1 点拉伸 |
| **枯萎** | 移除一张栽培区中的牌，不收获，也不返还原牌 |

**稀有度阶梯**：先古 > 稀有 > 罕见 > 普通（= 初始 = 事件 = 衍生）> 状态 = 任务 > 诅咒

## 8. 流派构成与曲线

### A. 加速栽培流
- **核心**：生长（春化、蚯蚓松土、催芽）与批量栽培（分株、母株）
- **爆发点**：春之祭 / 极限生长 / 腐熟 → 一回合内收获 2~3 张，转化为手牌优势
- **终结**：森林之主、深根、叶脉、腐殖循环 把「收获频率」变成永久成长
- **风险**：手牌消耗快，需要 切片呢 / 菌根 / 抽牌支撑

### B. 栽培库收益流
- **核心**：先把栽培库牌数堆到 3~4，再用栽培库牌数换数值
- **输出**：叶绿素爆发（×6）、光合风暴（重复）、落叶风暴（群体）、光合脉冲
- **防御**：老根、根系网络、树脂护壳、千年古树
- **种植的即时回报**：共生对随机敌人造成伤害，深根积累力量和敏捷
- **清库爆发**：杀植物 / 化雨 / 枯荣 —— 把"存量"一次性兑现

### 两流派的交汇
`杀植物`、`枯荣`、`春之祭` 都是「先把库堆高，再一次兑现」，是双流派的桥梁牌。

## 9. 数值基线

| 参考 | 数值 |
|---|---|
| 标准攻击 | 1 费 6 伤害 |
| 标准格挡 | 1 费 5 格挡 |
| 稀有度溢价 | 普通 ×1.0、罕见 ×1.3、稀有 ×1.7 |
| 栽培库牌数收益系数 | 1 点栽培库牌数 ≈ 1.5 伤害 / 2 格挡 / 0.15 能量 |
| 栽培库上限 | **无上限** |

**无上限带来的平衡约束**（重要）：

牌库无上限意味着「栽培库牌数」可以无限叠加，所以线性收益卡必须自带护栏，否则后期会失控：

| 类型 | 处理方式 | 已采用的卡 |
|---|---|---|
| 线性增伤（×N） | 保留，但提高费用或降低系数 | 叶绿素爆发（×6 / 2 费）、光合风暴（3 费） |
| 线性格挡（×N） | 系数压到 3~4 | 老根（×4）、气生根（×2） |
| 线性能量（×N） | **原则上要硬上限** | 千年古树（最多 1 点）；冠层已按设计确认改为**无上限**，属刻意破例 |
| 线性重复次数 | 依赖费用与出牌位，天然受限 | 光合脉冲、落叶风暴（每段对全体结算） |

> 设计原则：**伤害/格挡可以线性增长，能量与抽牌不行。** 能量和抽牌一旦线性，会直接导致无限循环。

**强度检查点**：
- 3 张库时：叶绿素爆发 18 伤害、老根 22 格挡 —— 属于「铺垫一回合后的合理回报」
- 6 张库时：叶绿素爆发 36 伤害（2 费）—— 已经很强，但需要先花 2~3 回合堆库，且中途不能用掉
- 无上限的极限：靠 母株 / 分株 / 幼芽 堆到 10+ 张时，单卡收益极高，这是**收益流的胜利条件**，可以接受
