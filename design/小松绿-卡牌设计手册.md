# 小松绿 · 卡牌设计手册 v0.1

> 目标：为「栽培」角色设计 89 张卡，支撑两个流派：
> **A. 加速栽培流** —— 缩短倒计时、批量栽培、提前收获
> **B. 栽培库收益流** —— 按「栽培库中的牌数」换取数值收益

---

## 1. 关键词与规则

| 关键词 | 定义 |
|---|---|
| **栽培** | 将 1 张手牌放入**栽培库**，X 回合后收获。X = 该牌**未升级原始费用**，钳制 1~3；状态/诅咒/任务按 1 计 |
| **栽培库** | 独立牌堆，界面独立显示，展示其中的牌与**剩余回合数**；**无上限** |
| **生长 N** | 栽培库中所有牌剩余回合 **-N**（最低 0，到 0 立即收获） |
| **延缓 N** | 剩余回合 **+N**（配套负面或延迟收益） |
| **收获** | 取出该牌，按稀有度升一档生成新牌（先古收同名牌），加入手牌；保留升级状态 |
| **栽培库牌数** | 结算时栽培库中的牌数（含剩余回合 >0 的全部牌） |

**稀有度阶梯**：先古 > 稀有 > 罕见 > 普通（= 初始 = 事件 = 衍生）> 状态 = 任务 > 诅咒

## 8. 流派构成与曲线

### A. 加速栽培流
- **核心**：生长（裸子植物、春化、蚯蚓松土、腐熟、菌丝蔓延）+ 批量栽培（分株、松露、移栽）
- **爆发点**：春之祭 / 极限生长 / 腐熟 → 一回合内收获 2~3 张，转化为手牌优势
- **终结**：森林之主、深根、叶脉、腐殖循环 把「收获频率」变成永久成长
- **风险**：手牌消耗快，需要 落叶归根 / 菌根 / 抽牌支撑

### B. 栽培库收益流
- **核心**：先把栽培库牌数堆到 3~4，再用栽培库牌数换数值
- **输出**：叶绿素爆发（×6）、光合风暴（重复）、落叶风暴（群体）、光合脉冲
- **防御**：老根、根系网络、树脂护壳、千年古树
- **增益**：煎蛋！/ 喜多护佑（本回合）、共生（常驻）
- **清库爆发**：化水 / 化雨 / 枯荣 —— 把"存量"一次性兑现

### 两流派的交汇
`化水`、`枯荣`、`春之祭` 都是「先把库堆高，再一次兑现」，是双流派的桥梁牌。

## 9. 数值基线

| 参考 | 数值 |
|---|---|
| 标准攻击 | 1 费 6 伤害 |
| 标准格挡 | 1 费 5 格挡 |
| 稀有度溢价 | 普通 ×1.0、罕见 ×1.3、稀有 ×1.7 |
| 栽培库牌数收益系数 | 1 点栽培库牌数 ≈ 1.5 伤害 / 2 格挡 / 0.15 能量 |
| 栽培库上限 | **无上限** |

**无上限带来的平衡约束**（重要）：

牌库无上限意味着「栽培库牌数」可以无限叠加，所以线性收益卡必须自带护栏，否则后期会失控：

| 类型 | 处理方式 | 已采用的卡 |
|---|---|---|
| 线性增伤（×N） | 保留，但提高费用或降低系数 | 叶绿素爆发（×6 / 2 费）、光合风暴（3 费） |
| 线性格挡（×N） | 系数压到 3~4 | 老根（×4）、气生根（×2） |
| 线性能量（×N） | **必须硬上限** | 冠层（每回合最多 2 点）、千年古树（最多 1 点） |
| 线性重复次数 | 依赖费用与出牌位，天然受限 | 光合脉冲、落叶风暴（群体，单次结算） |

> 设计原则：**伤害/格挡可以线性增长，能量与抽牌不行。** 能量和抽牌一旦线性，会直接导致无限循环。

**强度检查点**：
- 3 张库时：叶绿素爆发 18 伤害、老根 12 格挡 —— 属于「铺垫一回合后的合理回报」
- 6 张库时：叶绿素爆发 36 伤害（2 费）—— 已经很强，但需要先花 2~3 回合堆库，且中途不能用掉
- 无上限的极限：靠 母株 / 苔原 / 分株 堆到 10+ 张时，单卡收益极高，这是**收益流的胜利条件**，可以接受

## 11. 待定问题

1. **状态/诅咒的栽培价值**：目前收获是「垃圾换垃圾」，是否需要给诅咒额外补偿（例如立即生长）
2. **先古 ×2 的强度**：2 张同名先古牌非常强，是否需要限制「每场战斗只能栽培 1 张先古牌」
3. **栽培库牌数是否含剩余回合 0 的牌**：建议结算在收获前，即「到 0 但未结算」的牌仍计入
4. **加速是否应该有代价**：目前生长全部是正面，考虑给部分牌加"延缓"作为负面（已有 树脂封存/裸子植物/分株）
5. **无上限下的 UI 承载力**：栽培库假设能堆到 15+ 张，牌堆按钮与展开面板需要支持滚动

### 文案规范

1. **数字统一用阿拉伯数字**：`1 点能量`、`2 层虚弱`、`3 点格挡`
2. **条件句后置**：`造成 5 点伤害。若栽培库非空，改为 8 点。`
3. **栽培库牌数表述统一**：`栽培库中每有 1 张牌` 或 `等同于栽培库牌数`
4. **升级只改数字不改句式**：`造成 6 点伤害。` → `造成 9 点伤害。`
5. **关键词不展开**：栽培 / 生长 / 延缓 / 收获 由关键词提示条解释，卡面内不重复说明

## 13. 实现状态（v0.2）

**89 张全部已实现**，注册在 `ViridisCardPool`，卡面描述已进本地化。

### 几个与设计文本的差异

| 卡 | 设计 | 当前实现 | 原因 |
|---|---|---|---|
| 裸子植物 | 二选一：-1 或 +1 | 只实现加速（-1） | 二选一需要额外选择界面 |
| 移栽 | 栽培并**立即打出** | 栽培后**立即收获**，牌入手牌由玩家自己打出 | 自动打出会额外消耗一次出牌机会，手感等价 |
| 松脂 / 苔藓覆盖 / 顶芽 | “本回合栽培过” | 判定为“栽培库非空” | 未记录“本回合是否栽培”的状态 |
| 煎蛋！/ 喜多护佑 | 本回合力量/敏捷 | ✅ 本回合（回合结束移除） | — |
| 共生 | 每有 1 张库牌，攻击 +1 | 回合开始时获得等同于栽培库牌数的**本回合力量** | 力量只影响攻击伤害，数值等价 |
| 落叶归根 | 从弃牌堆取回 | ✅ 选择后入手 | — |
| 无性繁殖 | 复制库中 1 张 | 随机复制 1 张，剩余回合 1 | 未做牌库内选牌界面 |

### 能力类卡牌的钩子

新增 `CultivatePowerBase`，提供三个事件：

```csharp
OnCultivated(ctx, player)          // 每次栽培后
OnHarvested(ctx, player, card)     // 每次收获后
OnPileCleared(ctx, player, count)  // 清空牌库后
```

菌根、深根、年轮刻印、叶脉、森林之主、花芽分化、腐殖循环都挂在这三个钩子上。
