# 栽培（Cultivate）机制 Spec v0.1

> 状态：规则已定稿，数值待实测 ｜ 最后更新 2026-11-08
> 依据：本机游戏 v0.111.0 的 `sts2.dll` 实测数据（见文末「数据来源」）

---

## 1. 一句话

把一张牌埋进地里的机制：**该牌离开本场战斗**，经过 X 个回合后**收获 1 张稀有度更高一级的牌**。

## 2. 术语

| 词 | 含义 |
|---|---|
| 栽培 | 动作，同时是模组关键词（RitsuLib 铸造 `CardKeyword`）。由**初始遗物 / 药水 / 卡牌描述**执行 |
| 栽培目标 | 被埋进地里的那张牌 |
| X | 等待回合数 = 栽培目标**未升级时的原始费用**，钳制到 1~3 |
| 收获 | 倒计时归零时，把产物置入玩家手牌 |

**注意**：收获产物不带任何"栽培"标记，也不带关键词，避免自我循环。

## 3. 展示方式

栽培是模组关键词（`VIRIDIS_KEYWORD_CULTIVATE`），由 RitsuLib 注册，标题和说明放在 `card_keywords.json`。注册时 `CardDescriptionPlacement = None`，不向描述追加独立关键词行；真正执行栽培的动词卡在效果文本里用 `[gold]栽培[/gold]` 标出动作词。关键词值仍在 `CardModel.Keywords` 中，`IncludeInCardHoverTip` 默认开启，卡牌悬停提示会显示关键词说明。收益、触发类卡牌不挂这个词。

- 初始遗物（例如：每回合第一次……）
- 药水
- 卡牌效果文本（如"栽培手牌中的一张牌。"）

载体仍各自写效果文本；`card_keywords.json` 只保存关键词本身的标题与说明。

## 4. 结算流程

```
玩家执行栽培(target)
  → target 离开本场战斗（不进弃牌/消耗/手牌，不可再被检索）
  → 记录：卡牌 id、升级等级、X、剩余回合数
  → 每回合开始时，剩余回合数 -1
  → 归零时，在【回合开始时】把产物置入手牌
```

- 结算时点：**回合开始时**（玩家看到倒计时，拿到牌能立刻规划）。
- 战斗结束仍未收获 → 产物作废（本场战斗的临时物）。

### 4.1 永久栽培（特殊）

- 带“永久栽培”的牌是**被动**属性：只有被其它效果栽培时才生效，直接打出不会进入栽培区。
- 被栽培后不进入倒计时，`TurnsLeft` 视为无限，`Permanent = true`。
- 不参与收获，不产出卡牌；`生长`、`延缓`、`减半`、普通`立即收获`都跳过它。
- `清空栽培库`（枯荣、化水等）会把它一起移除，这是“其它效果可以将其移出”的实现。
- 回合结束触发型（如小松绿）在己方回合结束时结算，数值存在 `Planting.StoredBlock/StoredDamage`，每次结算后翻倍。
- 小松绿打出时会把该卡牌实例的 `DynamicVars` 翻倍，因此之后被栽培时从翻倍后的数值开始；栽培区内的触发只改 `StoredBlock/StoredDamage`，不再改卡牌实例。
- 战斗结束随栽培库一起清空。

## 5. X 的确定

| 栽培目标 | X |
|---|---|
| 原始费用 0 | 1 |
| 原始费用 1 | 1 |
| 原始费用 2 | 2 |
| 原始费用 3 | 3 |
| 原始费用 ≥4 | 3（钳制） |
| `HasEnergyCostX`（X 费牌） | 1 |
| 状态 / 诅咒 / 任务（不可打出的牌） | 1 |

"原始费用" = `CanonicalEnergyCost`，**忽略升级带来的费用变化**，也忽略战斗中的临时增减费。

## 6. 稀有度映射表

用户定义的阶梯（高→低）：

```
先古 > 稀有 > 罕见 > 普通 = 初始 = 事件 = 衍生 > 状态 = 任务 > 诅咒
```

对照引擎枚举 `MegaCrit.Sts2.Core.Entities.Cards.CardRarity`：

| 引擎枚举值 | 阶梯位置 | 收获目标的稀有度 |
|---|---|---|
| `Ancient` | 先古 | **同名卡 ×2**（特例，见 §8） |
| `Rare` | 稀有 | `Ancient` |
| `Uncommon` | 罕见 | `Rare` |
| `Common` / `Basic` / `Event` / `Token` | 普通 | `Uncommon` |
| `Status` / `Quest` | 状态 | `Common`（优先，见 §11 待定项） |
| `Curse` | 诅咒 | `Status`（按阶梯；见 §11 待定项） |

> **坑**：引擎枚举顺序是 `Basic→Common→Uncommon→Rare→Ancient→Event→Token→Status→Curse→Quest`，与本阶梯不一致，
> 因此**不能**直接用 `CardRarityExtensions.GetNextHighestRarityWithWrapping()`，必须自建映射表。

## 7. 收获池

**基础池**：小松绿角色卡池（`ModelDb.CardPool<ViridisCardPool>().AllCards`）。非先古收获只从这个池里选，不再并事件池、诅咒池、任务池或衍生池。

**诅咒特例**：栽培目标是诅咒（收获目标为 `Status`）时，改从全状态池选：

```csharp
ModelDb.CardPool<StatusCardPool>().AllCards
```

小松绿池里没有状态牌，不走这个特例会空池。

**先古特例**：栽培目标是先古牌时不做池检索，直接用被栽培牌的 `Id` 取回同名卡 ×2；跨角色先古牌也能取回，不再依赖当前角色池。

**过滤条件**：

1. `Rarity == 目标稀有度`
2. `CanBeGeneratedInCombat == true`（过滤后为空则放宽）
3. `CanonicalEnergyCost == X`（过滤后为空则回退同稀有度任意费用）

**空池回退**：

1. 忽略费用条件，取目标稀有度任意牌
2. 仍为空 → 不收获任何东西（不报错、不卡死）

## 8. 收获数量与属性

| 情况 | 数量 |
|---|---|
| 栽培目标为普通/罕见/稀有/状态/任务/诅咒 | **1 张** |
| 栽培目标为**先古** | **2 张相同的先古牌**（即被栽培的那张） |

- 允许两张同名。
- **保留升级**：栽培目标是升级过的，产物也是升级过的；产物本身不可升级则保持原样。
- **不保留附魔**：产物不带 `Enchantment`。
- **折扣**：若 X > 1，产物的费用在**第一次打出前降为 1**（`TemporaryCardCost.UntilPlayed(1)`）。
  X = 1 时不折扣。

## 9. 边界规则

| 情况 | 规则 |
|---|---|
| 手牌已满 | 产物进**弃牌堆** |
| 栽培目标为 X 费牌 | X = 1；收获池排除所有 `HasEnergyCostX` 的牌 |
| 栽培目标带附魔 | 附魔随目标一起消失，不影响 X |
| 同一张牌被栽培两次 | 目标已离开战斗，不可能；同名不同副本可以分别栽培 |
| 战斗结束/玩家死亡 | 未结算的栽培作废 |
| 产物是否触发"获得卡牌"类联动 | 待定（默认：不触发） |
| 栽培是否算"消耗/移除" | 不算，不触发消耗联动 |

## 10. 实现映射（待验证）

| 需求 | 引擎 API |
|---|---|
| 费用降为 1 直到打出 | `TemporaryCardCost.UntilPlayed(1)`（`ClearsWhenCardIsPlayed`） |
| 读原始费用 | `CardModel.CanonicalEnergyCost` |
| 读稀有度 | `CardModel.Rarity` |
| 枚举角色池 | `CardPoolModel.AllCards` / `GetUnlockedCards(...)` |
| 枚举事件池 | `ModelDb.CardPool<EventCardPool>()` |
| 生成卡牌实例 | `ModelDb.Card<T>()`（或 `CardModel` 克隆） |
| 置入手牌 | 待查（`CardPile` / `CardCmd` 相关） |
| 回合开始钩子 | 待查（`CombatStateHooks` 或 Power 的 turn-start） |

状态保存建议：用一个挂在玩家身上的战斗内 Power 存列表（卡 id + 升级等级 + 剩余回合），
Power 自带回合开始回调，且战斗结束自动销毁，比静态字典安全。

## 11. 待定项

1. **诅咒的收获目标**：已定：产出 `Status`，从全状态池随机（见 §7）。
2. **状态/任务的收获目标**：目前只用 `Common`，不接受 `Basic`/`Event`/`Token`。
3. **栽培目标范围**：仅手牌？还是也允许抽牌堆/弃牌堆？
4. **先古 ×2 的确认**：已定：2 张被栽培的那张牌；跨角色用全局 `Id` 查回同名。
5. **产物是否触发"获得卡牌"联动**。
6. **先古档是否限流**：小松绿池只有 2 张先古，产出随机性较大。
